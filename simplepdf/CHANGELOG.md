# Changelog

## 0.2.0
- Page manager: rotate, delete, reorder, merge, extract
- Edit existing text, add text, check/cross, date, signature, highlight, pen and eraser
- Move, resize and delete placed marks
- Page navigation in preview, print
- Convert to Excel, Word (text only) and Text
- Open password-protected PDFs and save a copy without the password
- Not included: create password (removed until a verified encryption engine is added)
